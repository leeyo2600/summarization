law_summary - 의견조회 요약 도우미 (HTML + Flask)

1. ZIP 전체를 쓰기 가능한 폴더에 압축 해제합니다.
2. law_summary 폴더 안의 law_summary.cmd를 더블클릭합니다.
3. 문서, OpenAI API 키, 국가법령정보 API 키를 입력합니다.
4. 외부 전송 동의를 확인하고 생성합니다.

대상은 Windows x64입니다. Python, Java, 패키지 설치와 PATH 설정이 필요 없습니다.
내장 Python 3.13과 필수 패키지, HWP용 Java 및 변환기를 모두 포함합니다.
실행 중 패키지/모델 다운로드, pip 실행, 가상환경 생성은 하지 않습니다.

마지막으로 입력한 두 API 키는 자동 저장되며 프로그램을 다시 열면 복원됩니다.
입력값을 수정하면 새 값으로 교체하고, 지우면 해당 저장값도 지웁니다.
저장 상태는 입력란 아래에 표시됩니다. 저장 실패 시 현재 입력값으로 작업할 수 있지만
다음 실행에 복원되지 않을 수 있으므로 표시된 오류를 확인하세요.
키는 프로그램 폴더의 .local/credentials.json에 Windows 사용자 암호화(DPAPI)로 저장합니다.
저장된 키는 같은 PC의 같은 Windows 계정에서 복원됩니다. 다른 PC/계정에서는 다시 입력하세요.
API 키 옆의 보기/숨기기 버튼으로 입력값을 확인할 수 있습니다.
외부 전송 동의는 작업마다 직접 확인합니다.

OpenAI API에 직접 연결하며 요약과 소관부서 추천에 기존 모델을 사용합니다.
법령 조회, 요약, 조문 추출, 소관부서 추천, 엑셀 생성 알고리즘은 유지했습니다.
처음 실행하면 output 폴더를 준비하고, config.json이 없으면 config.example.json에서 복원합니다.

자료 등록 → 요약 생성 → 결과 확인 순서로 사용합니다.
브라우저가 자동으로 열리지 않으면 실행 창의 http://127.0.0.1 주소를 엽니다.
처리 중 화면을 새로고침해도 같은 브라우저에서 진행 중인 작업을 다시 확인합니다.
실행 창은 열어두세요. 종료할 때 Ctrl+C를 누르거나 실행 창을 닫습니다.
기본 포트 8501이 사용 중이면 다른 빈 포트를 선택하며 저장된 키는 그대로 복원됩니다.
다른 PC로 옮길 때는 law_summary 폴더 전체를 복사하세요.

실제 요약/법령 조회에는 유효한 API 키와 네트워크 연결이 필요합니다.
사용자 업무 문서, 이전 처리 결과, API 키는 배포 ZIP에 포함하지 않습니다.

점검: law_summary.cmd --check
브라우저 없이 실행: law_summary.cmd --no-browser
실행 진단: law_summary_startup.log
Python 라이선스: runtime/python/LICENSE.txt
Java 및 패키지 라이선스는 각각의 배포 폴더에 보존합니다.
