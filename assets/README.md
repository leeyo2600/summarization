## 글자와 여백 기준 (2026-09-29)

[KRDS 타이포그래피](https://www.krds.go.kr/html/site/style/style_03.html)의 본문 최소 16px, 행간 150% 이상과 제목 계층을 참고합니다. Noto Sans KR는 유지하며 본 앱에는 다음과 같이 적용했습니다. KRDS 전체 준수 인증을 뜻하지 않습니다.

| 역할 | 데스크톱 | 모바일 | 줄 높이 |
| --- | --- | --- | --- |
| 페이지 제목 | 32px | 24px | 1.5 |
| 영역 제목 | 24px | 20px | 1.5 |
| 본문·입력·생성 버튼 | 16px | 16px | 1.5 |
| 보조 정보 | 14px | 14px | 1.5 |

본문 대비 영역 제목은 1.5배(모바일 1.25배)입니다. 자간은 0으로 통일합니다. 위 값은 브라우저 기본 글자 크기 16px일 때이며 실제 CSS는 확대를 고려한 `rem`과 단위 없는 줄 높이를 사용합니다.

[KRDS 간격 안내](https://www.krds.go.kr/html/site/outline/outline_03.html)의 8포인트 기본 그리드를 참고하여 주요 간격은 8·16·24·32px, 미세 간격은 4·12px로 통일했습니다. 단계 버튼은 최소 높이 48px, 데스크톱 상하 12px·좌우 16px의 간결한 표시를 사용합니다. 숫자와 단계명은 같은 글자 크기·줄 높이로 한 줄에 배치하고 기준선을 맞춥니다. “현재 단계” 문구는 없애고 기본 버튼의 강조 색상과 도움말로 현재 위치를 구분합니다. 키보드 Tab과 Enter로도 이동할 수 있습니다. 좁은 화면에서도 숫자는 유지하며 글자 크기와 간격을 줄입니다. 아이콘과 버튼 글자는 8px 간격입니다.

문서 선택의 빈 업로드 영역은 버튼과 용량 안내를 세로 중앙 정렬하며 둘 사이에 16px 간격을 둡니다. `--law-upload-height`는 두 개의 인증 입력란 높이, OC 레이블과 입력란 사이 간격에서 계산해 데스크톱에서 OC 입력란 아래쪽과 맞춥니다. 파일이 선택되면 목록을 억지로 중앙 정렬하거나 잘라내지 않습니다. 제목·입력란의 `?`는 텍스트 바로 옆에 배치하고, 페이지 제목의 자동 링크 아이콘은 `anchor=False`로 제거합니다.

문서 선택·인증정보의 바깥 상자는 `st.container(height='stretch')`로 같은 행의 더 긴 상자에 높이를 맞춥니다. 고정 픽셀 높이 없이 업로드 목록이 늘어나면 인증정보 상자도 함께 늘어나며, 모바일에서 세로로 쌓이면 각각 내용 높이를 사용합니다. 데스크톱 안쪽 여백은 위·좌우 24px, 아래 16px로 하단 빈 공간을 줄이고, 모바일에서는 모두 16px로 합니다. 외부 전송 동의는 공통 레이블의 아래 여백을 제거하고 18px 체크박스를 24px 높이인 첫 글줄의 중앙에 맞춥니다. 문장이 여러 줄로 나뉘어도 첫 줄 기준을 유지하며 기본 체크박스의 클릭·키보드·동의 검증 동작은 변경하지 않습니다. 물음표를 감싸는 기본 span의 추가 왼쪽 여백을 제거하고 공통 8px 간격만 적용합니다.

활성 단계에는 2px 올라온 위치와 남색의 옅은 그림자를 적용합니다. `law-step-lift`는 0.24초 동안 한 번만 실행되며 반복해서 흔들리지 않습니다. `prefers-reduced-motion: reduce`에서는 애니메이션과 위치 이동을 끄고 색상·그림자만 유지합니다. 단계는 Streamlit 기본 버튼으로 구성한 탐색 메뉴입니다. 완료 후 자료 등록과 결과 확인을 오가도 같은 세션의 결과가 유지됩니다. 진행 중에는 다른 단계가 비활성화되어 중복 작업을 시작하지 않습니다.

진행 카드(`processing_status`)의 항목 간격은 8px, 경과시간 영역의 추가 패딩은 0, 로딩 문구의 세로 패딩은 4px로 제한했습니다. 완료 화면의 건수 표시에는 이 간격 변경을 적용하지 않습니다.

[KRDS 버튼 가이드](https://www.krds.go.kr/html/site/component/component_05_02.html)를 참고해 생성 버튼은 문서 추가 아이콘과 텍스트를 함께 표시합니다. 활성 색상 `#005ea8`, 호버 `#004b87`, 눌림 `#003764`, 비활성 `#e8eff7`은 본 앱에 맞춘 선택입니다. 필수 입력 미완료 시의 비활성 동작은 유지합니다. 공통 값은 `web.css`의 `--law-*` 변수에서 관리합니다.
