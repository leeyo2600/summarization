실행 방법
1. 실행 중인 이전 버전 프로그램을 종료합니다. 기존 검은 실행창도 닫아 주세요.
2. v3 ZIP 전체를 새 폴더에 압축 해제합니다. ZIP 안에서 바로 실행하지 마세요.
3. law_summary 폴더 안의 law_summary.cmd를 더블클릭합니다.
4. 브라우저 탭 제목에 v3가 표시되는지 확인합니다.
5. API 키가 비어 있으면 다시 입력하고, 기존 원본 문서를 올려 다시 처리합니다.

수정 내용
- 정보시스템1과장, 정보시스템2과장 등 숫자를 포함한 부서장 이름을 인식합니다.
- 동일 법령 내 다른 조문·항·호를 참조하는 업무를 실제 원문으로 펼쳐 읽습니다.
- 1~11호 및 16~20호와 같은 여러 범위와 연쇄 참조를 처리합니다.
- 적용 범위 및 예외 문구와 인용 출처를 함께 보존합니다.
- 삭제된 호는 업무에서 제외합니다.
- 인용 대상 누락 또는 순환 참조는 오류 이유를 표시합니다.
  근거가 불완전한 상태에서 임의로 부서를 추천하거나 '없음'으로 채우지 않습니다.
- 브라우저 탭 제목에 v3를 표시합니다. 기존 화면 구성은 유지합니다.
